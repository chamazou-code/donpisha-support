1台で遊ぶとき

「みんなで遊ぶ」で1台のスマホを回して遊ぶあいだ データはこの端末から出ません 名前 とくてん マイカードは端末の中にだけ保存されます

オンラインで遊ぶとき

部屋を作る または入ると 遊ぶために必要な次の情報だけをサーバーに預かります

  • 部屋のコードと設定
  • 端末ごとの匿名ID
  • 入力した表示名とアバターの番号
  • ゲームで使うお題と選択肢
  • 各レースで選んだ順位と主役が書いた理由
  • その部屋に出したマイカード

これらは部屋ができてから24時間でサーバーから自動的に削除されます

マイカードを持ち寄るとき

部屋を作った人が「みんなのマイカードも使う」を選んだ場合 参加者は自分で確認したうえで1人20枚までその部屋に出せます 黙って送られることはありません

部屋を作った人は 山を作るために出されたカードの内容をすべて読むことができます そのほかの参加者に見えるのは山に入ったカードだけです

「取り下げる」で共有をやめられるのはゲームが始まる前のロビーにいる間だけです ゲーム開始後や自分の画面で部屋から出た後も カードは部屋を作ってから24時間がたつまでサーバーに残ることがあります

購入を確認するとき

買い切り機能の購入と復元を確認するため Appleが署名した購入情報をサーバーで検証し 次の情報を購入台帳に保存します

  • Appleの環境 Production Sandbox と商品ID dev.donpisha.pass.create
  • Appleが発行する仮名化された取引ID original transaction ID latest transaction ID
  • Appleから提供された場合の appTransactionId appAccountToken
  • 購入 検証 返金または取り消しの日時と 現在の購入状態

検証に使う生のレシートデータやAppleの署名データ JWS は保存しません クレジットカード番号などの支払情報はAppleが扱い このアプリとサーバーは受け取らず 保存もしません

購入台帳は 買い切り機能の復元 返金や取り消しの反映 同じ購入の不正な使い回しを防ぐため サービス提供に必要な期間保持します 購入台帳は部屋データではないため 部屋データの24時間削除とは別です

購入台帳と匿名IDとの一時的なひも付け claim は 最後に購入を確認してから90日間使われなかった匿名IDを自動清掃するときに一緒に削除されます 使っている間は購入状態の確認に必要なため保持します その場合も 復元や返金の反映に必要な購入台帳本体は残ります

集めていないもの

  • 氏名 住所 電話番号 メールアドレス
  • 位置情報 連絡先 写真
  • 広告IDや端末をまたいで追跡する識別子
  • アクセス解析や広告のための行動記録

表示名とマイカード

表示名は一緒に遊ぶ人に見えます マイカードは部屋を作った人には出したものすべてが そのほかの参加者には山に入ったものだけが見えます 本名でなくてかまいません 部屋を作った人や参加者に見せてもよい内容か確かめてから入力してください

外部サービス

オンラインの部屋はSupabaseのサーバーで動いています 現在のアプリ内購入はAppleが扱います それ以外の会社へデータを販売することはありません

部屋を閉じるときと 削除のお問い合わせ

部屋を作った人が「部屋を閉じる」を押すと 部屋はすぐに閉じ 参加者は開けなくなります サーバー上のデータはその場では消えず 部屋の作成から24時間後に自動的に削除されます

端末内のデータはアプリを削除すると一緒に削除されます
